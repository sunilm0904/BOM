Works with any column layout or header wording — headers can be anywhere in the first ~40 rows, in any case, and named things like "Part No", "Manufacturer Part No.", "Material Code", "Item Code", etc. Reads every sub-sheet inside each uploaded file (skips sheets with no usable data, e.g. notes/revision tabs). Matching order: 1) exact part number, 2) near-match part number (typos/formatting), 3) description similarity — shown as "Partially matching — NN%" when it's not a full match. Placeholder values like "NA", "TBD", or "-" are ignored as part numbers so description matching takes over instead. Where a part number is genuinely duplicated across BOMs, the description is used to pick the right one. Where nothing disambiguates, the most recently uploaded BOM wins. The download writes only the price values directly into your original enquiry file's underlying XML — row colours, logos, and other formatting are left completely untouched.
