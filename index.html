How it reads your files: headers can sit anywhere in the first ~40 rows and may be written in any style (“Unit Price”, “Unit Rate”, “Rate”, “Supply Rate”, “Net Price”, “Part_No.”, “Material Code”…), and every sheet of every file is checked — each historical BOM may use different column names. Total / Qty / Amount columns are never mistaken for the unit price. Matching order: 1) exact part number ignoring spaces, dashes and symbols, 2) look-alike characters (O/0, I/1), 3) prefix/suffix differences, 4) typos, 5) description. If an item is in several BOMs, the highest price is filled. Prices already in the enquiry are kept unless you tick “overwrite”. The download edits only the price cells of your original .xlsx, so formatting, logos and formulas stay untouched. After matching, open “Data check” to see which column was used from each file.
